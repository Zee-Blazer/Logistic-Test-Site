# Logistic-Test-Site

Luxury hair brand & salon delivery website built with Next.js (App Router), TypeScript, and Tailwind CSS.

## Features
- **Editorial Brand Presentation**: Refined luxury aesthetic with custom typography and color tokens.
- **Product Discovery & Shop**: Hair catalogue with client-side category filtering (Wigs, Bundles, Closures, Frontals).
- **Salon Services & Booking**: Service menu with client-side validated appointment request form.
- **WhatsApp Integration**: Direct click-to-chat order and booking inquiries with pre-formatted messages.
- **Responsive & Accessible**: Optimized for mobile, tablet, and desktop viewing.

## Getting Started

Run the development server:

```bash
npm run dev
```

Or build for production:

```bash
npm run build
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
